**Structure \& Layout:**

<html> → Root element of the page

<head> → Metadata, title, styles, scripts

<body> → Main content of the page

<header> → Top section (logo, navigation, title)

<nav> → Navigation menus (links to sections/pages)

<main> → Central content area

<section> → Grouping related content (e.g., announcements, resources)

<article> → Independent content (e.g., blog post, news update)

<footer> → Bottom section (contact info, copyright)

**Content \& Text:**

<h1> to <h6> → Headings for titles and subsections

<p> → Paragraphs

<span> → Inline text styling

<strong> / <em> → Bold and italic emphasis

<ul>, <ol>, <li> → Lists (bullet points or numbered)

<table>, <tr>, <td>, <th> → Tabular data (e.g., schedules, grades)


**Links \& Media:**

<a> → Hyperlinks (to other pages or resources)

<img> → Images (student photos, logos)

<video> / <audio> → Multimedia content

<iframe> → Embedding external content (e.g., YouTube, Google Forms)

### **Forms (for student login, feedback, registration):**

<form> → Container for input fields

<input> → Text boxes, checkboxes, radio buttons

<textarea> → Larger text input (feedback, comments)

<select> / <option> → Dropdown menus

<button> → Submit or action buttons

<label> → Describes input fields


 **CSS TAGS :**


 **Text \& Fonts**

**color → Text color**

**font-size → Size of text**

**font-family → Typeface (e.g., Arial, Times New Roman)**

**text-align → Alignment (left, center, right)**

**font-weight → Boldness**

 **Backgrounds**

**background-color → Solid background color**

**background-image → Add images as background**

**background-size → Cover, contain, etc.**


 **Box \& Layout**

**margin → Space outside element**

**padding → Space inside element**

**border → Outline around element**

**width, height → Size control**

**display → Block, inline, flex, grid**

**Flexbox/Grid (for dashboard-style layouts)**

**display: flex; → Flexible box layout**

**justify-content → Horizontal alignment**

**align-items → Vertical alignment**

**display: grid; → Grid layout**

**grid-template-columns → Define column structure**


 **Buttons \& Links**

**background-color → Button color**

**border-radius → Rounded corners**

**cursor: pointer; → Pointer on hover**

**hover pseudo-class → Change style when mouse hovers**
