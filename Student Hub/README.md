# Student Hub Portal

A centralized, responsive web interface built to help university students, faculty, and administrators access academic updates, track attendance, manage fees, and view upcoming campus events efficiently. Designed and developed for CHARUSAT University.

---

## 🌟 Key Features

* **Student Dashboard**: Quick access to overall attendance rates, fee payment statuses, class timetables, and recent announcements.
* **Attendance Tracking**: Subject-wise class tracking complete with interactive progress visual indicators.
* **Fee Management**: Summary cards showing total, paid, and remaining fees along with a complete transaction history table.
* **Campus Events & Registration**: View upcoming hackathons, cultural festivals, technical workshops, and sports events.
* **Administrator Panel**: High-level metrics for faculty and student tracking, coupled with rapid portal management actions.
* **Support & Engagement**: Direct contact forms, frequently asked questions (FAQ), settings, and portal feedback channels.

---

## 🛠️ Built With

* **HTML5**: Semantic markup for accessible page structuring.
* **CSS3**: Custom styling using CSS Flexbox and CSS Grid layouts for modern components.
* **Responsive Design**: Mobile-friendly navigation, grids, and card components across all devices.
